# ОСББ Академоселя: бот «ЖКГ-Агент»

Telegram-бот для ОСББ на Стрітенській 17: меню кнопками (аварії, оплата, лічильники, контакти, звернення) і AI-агент із базою знань (Google Docs, Google Sheets).
Другий проєкт власника, окремий від ARCHI. Працює на тому ж n8n Cloud (`osbbcopilot.app.n8n.cloud`), workflow `YcbuzP4ii03B6Mtk` («My workflow 2»).

Стан на 14.11.2026 (live n8n, під час сесії ARCHI): workflow активний, у листопаді 0 виконань; AI Agent — Claude Haiku 4.5, памʼять розмови в Postgres (`n8n_chat_histories`); Pinecone вимкнено.

Старт сесії: прочитати `CLAUDE.md`, потім `docs/HANDOFF_FROM_ARCHI.md`.
