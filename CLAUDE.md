# ОСББ: ЗАФІКСОВАНІ ПРАВИЛА (проєкт «ЖКГ-Агент»)

Якщо сесія не бачить цього файлу, вона на чужому репозиторії: зупинитись і сказати першим рядком.

## Правила, перенесені з ARCHI (власник, 14.11.2026: «з ОСББ працюємо так само»)
1. **Мова:** українська. Відповіді власнику стовпчиком: один показник — один рядок.
2. **Виконання n8n (ліміт тарифу, спільний з ARCHI).** Тариф Starter: 2 500 виконань на місяць на весь інстанс. Кожен тригер за розкладом перед публікацією отримує розрахунок «виконань на місяць» проти ліміту; цифру показати власнику до публікації. Опитування кожні N хвилин для «перевірки умови» заборонено. Після публікації надіслати боту `/start` і перевірити, що виконання з'явилось. Причина правила: 13.11.2026 ліміт вичерпано, усі тригери зупинились.
3. **Credentials.** Токен бота не писати в URL вузла: тільки credential n8n. Після створення workflow через SDK звірити credentials кожного вузла.
4. **Зміни n8n через MCP:** записати ID відкату (`activeVersionId`) до зміни; `update_workflow`; звірка версій `get_workflow_versions_diff`; `publish_workflow` після звірки. Код у Code-вузлі: лише `setNodeParameter` зі шляхом `/jsCode`.
5. **Персональні дані співвласників** (імена, площі, контакти) не копіювати в репозиторій, у документи й у запити до зовнішніх сервісів.
6. **Нічого не робити в живому n8n без «так» власника**, крім читання.
7. **Правда понад усе:** число без джерела не писати; позначати «live», «розрахунок вручну» або «не перевірено».
8. **Репозиторій приватний.** Токени в git не комітити; експорт workflow з заглушкою `<TELEGRAM_BOT_TOKEN>`.
